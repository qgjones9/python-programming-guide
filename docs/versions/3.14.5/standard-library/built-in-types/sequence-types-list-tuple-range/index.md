# [Sequence Types — list, tuple, range](https://docs.python.org/3/library/stdtypes.html#sequence-types-list-tuple-range)

Sequence types are Python's built-in way to represent ordered collections of objects. The most common sequence types are `list` (mutable), `tuple` (immutable), and `range` (arithmetic progressions). All sequence types support a shared set of operations—such as indexing, slicing, iteration, and membership testing—but each type has its own characteristics and use-cases. This page introduces these core sequence types and provides links to detailed discussions of their behaviors and methods.


| Subject | Description |
|---------|-------------|
| [Lists](lists/index.md) | Mutable ordered sequences with methods for append, extend, sort, and other in-place updates. |
| [Tuples](tuples/index.md) | Immutable ordered sequences often used for fixed records and hashable composite keys. |
| [Ranges](ranges/index.md) | Lazy arithmetic progressions used mainly in `for` loops and indexing. |
| [Common Sequence Operations](common-sequence-operations/index.md) | Operations shared by sequences such as indexing, slicing, concatenation, repetition, and membership tests. |
| [Immutable Sequence Types](immutable-sequence-types/index.md) | Sequence types that cannot change after creation, including `tuple`, `str`, `bytes`, and `range`. |
| [Mutable Sequence Types](mutable-sequence-types/index.md) | Sequence types you can update in place, chiefly `list` and `bytearray`. |
