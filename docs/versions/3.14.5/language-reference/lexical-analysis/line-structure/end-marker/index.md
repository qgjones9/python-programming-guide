# [End marker](https://docs.python.org/3/reference/lexical_analysis.html#end-marker)

At the end of non-interactive input, the lexical analyzer generates an [`ENDMARKER`](../../../../standard-library/python-language-services/token-constants-used-with-python-parse-trees/index.md#end-of-file-and-source-encoding) token.

```python
>>> 1 + 2
3
>>> 
```


**How do I enter an endmarker?**

You don't need to type or enter the end marker (`ENDMARKER`) manually. It is automatically generated by Python's tokenizer at the end of a file or input stream when no more source code follows. 

Whenever the Python interpreter reaches the **end of a script, module, or input**, it places an `ENDMARKER` token after the final logical line. For example, after the last line in a `.py` file, or when you submit the last entry in interactive mode, the end marker is inserted.

**You cannot enter the ENDMARKER directly in your code**; it's an internal detail, not something the programmer types. If you use tools like [`tokenize`](https://docs.python.org/3/library/tokenize.html), you'll see the `ENDMARKER` token as the last token when all input has been processed.

Example showing the ENDMARKER with the `tokenize` module:

```python
import tokenize

with open("example.py", "rb") as f:
    tokens = list(tokenize.tokenize(f.readline))
    for token in tokens:
        print(token)
```

The final token printed will have the type `ENDMARKER`:

```
TokenInfo(type=0 (ENDMARKER), ... )
```

So: **Just end your file or input; Python will insert the ENDMARKER for you automatically.**
