# [generator](https://docs.python.org/3.14/glossary.html#term-generator)

A function which returns a [generator iterator](../generator-iterator/index.md).  It looks like a normal function except that it contains [yield](https://docs.python.org/3.14/reference/simple_stmts.html#yield) expressions for producing a series of values usable in a for-loop or that can be retrieved one at a time with the [next()](https://docs.python.org/3.14/library/functions.html#next) function.

Usually refers to a generator function, but may refer to a

*generator iterator* in some contexts.  In cases where the intended meaning isn’t clear, using the full terms avoids ambiguity.
