# [index](https://docs.python.org/3.14/glossary.html#term-index)

A numeric value that represents the position of an element in a [sequence](../sequence/index.md).

In Python, indexing starts at zero.

For example, `things[0]` names the *first* element of `things`; `things[1]` names the second one.

In some contexts, Python allows negative indexes for counting from the end of a sequence, and indexing using [slices](../slice/index.md).

See also [subscript](../subscript/index.md).
