# [callable](https://docs.python.org/3.14/glossary.html#term-callable)

A callable is an object that can be called, possibly with a set of arguments (see [argument](../argument/index.md)), with the following syntax:

```python
callable(argument1, argument2, argumentN)
```

A [function](../function/index.md), and by extension a [method](../method/index.md), is a callable. An instance of a class that implements the [__call__()](https://docs.python.org/3.14/reference/datamodel.html#object.__call__) method is also a callable.
