# [generic function](https://docs.python.org/3.14/glossary.html#term-generic-function)

A function composed of multiple functions implementing the same operation for different types. Which implementation should be used during a call is determined by the dispatch algorithm.

See also the [single dispatch](../single-dispatch/index.md) glossary entry, the [functools.singledispatch()](https://docs.python.org/3.14/library/functools.html#functools.singledispatch) decorator, and [PEP 443](https://peps.python.org/pep-0443/).
