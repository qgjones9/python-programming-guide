# [generic type](https://docs.python.org/3.14/glossary.html#term-generic-type)

A [type](../type/index.md) that can be parameterized; typically a [container class](https://docs.python.org/3.14/reference/datamodel.html#sequence-types) such as [list](https://docs.python.org/3.14/library/stdtypes.html#list) or [dict](https://docs.python.org/3.14/library/stdtypes.html#dict). Used for [type hints](../type-hint/index.md) and [annotations](../annotation/index.md).

For more details, see [generic alias types](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias), [PEP 483](https://peps.python.org/pep-0483/), [PEP 484](https://peps.python.org/pep-0484/), [PEP 585](https://peps.python.org/pep-0585/), and the [typing](https://docs.python.org/3.14/library/typing.html#module-typing) module.
