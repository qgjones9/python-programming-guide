# [type](https://docs.python.org/3.14/glossary.html#term-type)

The type of a Python object determines what kind of object it is; every
object has a type.  An object’s type is accessible as its
[__class__](https://docs.python.org/3.14/reference/datamodel.html#object.__class__) attribute or can be retrieved with
`type(obj)`.
