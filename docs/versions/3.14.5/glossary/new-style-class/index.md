# [new-style class](https://docs.python.org/3.14/glossary.html#term-new-style-class)

Old name for the flavor of classes now used for all class objects.  In earlier Python versions, only new-style classes could use Python’s newer, versatile features like [__slots__](https://docs.python.org/3.14/reference/datamodel.html#object.__slots__), descriptors, properties, [__getattribute__()](https://docs.python.org/3.14/reference/datamodel.html#object.__getattribute__), class methods, and static methods.
