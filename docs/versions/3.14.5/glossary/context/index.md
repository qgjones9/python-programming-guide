# [context](https://docs.python.org/3.14/glossary.html#term-context)

This term has different meanings depending on where and how it is used. Some common meanings:

| Term |
|------|
| The temporary state or environment established by a [context manager](../context-manager/index.md) via a [with](https://docs.python.org/3.14/reference/compound_stmts.html#with) statement. |
| The collection of key­value bindings associated with a particular [contextvars.Context](https://docs.python.org/3.14/library/contextvars.html#contextvars.Context) object and accessed via [ContextVar](https://docs.python.org/3.14/library/contextvars.html#contextvars.ContextVar) objects.  Also see [context variable](../context-variable/index.md). |
| A [contextvars.Context](https://docs.python.org/3.14/library/contextvars.html#contextvars.Context) object.  Also see [current context](../current-context/index.md). |
