# [text file](https://docs.python.org/3.14/glossary.html#term-text-file)

A [file object](../file-object/index.md) able to read and write [str](https://docs.python.org/3.14/library/stdtypes.html#str) objects. Often, a text file actually accesses a byte-oriented datastream and handles the [text encoding](../text-encoding/index.md) automatically. Examples of text files are files opened in text mode (`'r'` or `'w'`), [sys.stdin](https://docs.python.org/3.14/library/sys.html#sys.stdin), [sys.stdout](https://docs.python.org/3.14/library/sys.html#sys.stdout), and instances of [io.StringIO](https://docs.python.org/3.14/library/io.html#io.StringIO).

See also [binary file](../binary-file/index.md) for a file object able to read and write [bytes-like objects](../bytes-like-object/index.md).
