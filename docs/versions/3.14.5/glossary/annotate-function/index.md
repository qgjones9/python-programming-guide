# [annotate function](https://docs.python.org/3.14/glossary.html#term-annotate-function)

A callable that can be called to retrieve the [annotations](../annotation/index.md) of
an object. Annotate functions are usually [functions](../function/index.md),
automatically generated as the [__annotate__](https://docs.python.org/3.14/reference/datamodel.html#object.__annotate__) attribute of functions,
classes, and modules. Annotate functions are a subset of
[evaluate functions](../evaluate-function/index.md).
