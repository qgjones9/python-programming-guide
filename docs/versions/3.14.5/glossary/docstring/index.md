# [docstring](https://docs.python.org/3.14/glossary.html#term-docstring)

A string literal which appears as the first expression in a class, function or module.  While ignored when the suite is executed, it is recognized by the compiler and put into the [__doc__](https://docs.python.org/3.14/library/stdtypes.html#definition.__doc__) attribute of the enclosing class, function or module.  Since it is available via introspection, it is the canonical place for documentation of the object.
