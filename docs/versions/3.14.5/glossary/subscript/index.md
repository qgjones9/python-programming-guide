# [subscript](https://docs.python.org/3.14/glossary.html#term-subscript)

The expression in square brackets of a
[subscription expression](https://docs.python.org/3.14/reference/expressions.html#subscriptions), for example,
the `3` in `items[3]`.
Usually used to select an element of a container.
Also called a [key](../key/index.md) when subscripting a [mapping](../mapping/index.md),
or an [index](../index/index.md) when subscripting a [sequence](../sequence/index.md).
