# [slice](https://docs.python.org/3.14/glossary.html#term-slice)

An object of type [slice](https://docs.python.org/3.14/library/functions.html#slice), used to describe a portion of a [sequence](../sequence/index.md). A slice object is created when using the [slicing](https://docs.python.org/3.14/reference/expressions.html#slicings) form of [subscript notation](https://docs.python.org/3.14/reference/expressions.html#subscriptions), with colons inside square brackets, such as in `variable_name[1:3:5]`.
