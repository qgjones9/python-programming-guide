# [meta path finder](https://docs.python.org/3.14/glossary.html#term-meta-path-finder)

A [finder](../finder/index.md) returned by a search of [sys.meta_path](https://docs.python.org/3.14/library/sys.html#sys.meta_path).  Meta path finders are related to, but different from [path entry finders](../path-entry-finder/index.md).

See [importlib.abc.MetaPathFinder](https://docs.python.org/3.14/library/importlib.html#importlib.abc.MetaPathFinder) for the methods that meta path finders implement.
