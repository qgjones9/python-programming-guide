# [universal newlines](https://docs.python.org/3.14/glossary.html#term-universal-newlines)

A manner of interpreting text streams in which all of the following are
recognized as ending a line: the Unix end-of-line convention `'\n'`,
the Windows convention `'\r\n'`, and the old Macintosh convention
`'\r'`.  See [PEP 278](https://peps.python.org/pep-0278/) and [PEP 3116](https://peps.python.org/pep-3116/), as well as
[bytes.splitlines()](https://docs.python.org/3.14/library/stdtypes.html#bytes.splitlines) for an additional use.
