# [dictionary](https://docs.python.org/3.14/glossary.html#term-dictionary)

An associative array, where arbitrary keys are mapped to values.  The keys can be any object with [__hash__()](https://docs.python.org/3.14/reference/datamodel.html#object.__hash__) and [__eq__()](https://docs.python.org/3.14/reference/datamodel.html#object.__eq__) methods. Called a hash in Perl.
