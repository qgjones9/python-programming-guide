# [mutable](https://docs.python.org/3.14/glossary.html#term-mutable)

An [object](../object/index.md) with state that is allowed to change during the course of the program.  In multi-threaded programs, mutable objects that are shared between threads require careful synchronization to avoid [race conditions](../race-condition/index.md).  See also [immutable](../immutable/index.md), [thread-safe](../thread-safe/index.md), and [concurrent modification](../concurrent-modification/index.md).
