# [special method](https://docs.python.org/3.14/glossary.html#term-special-method)

A method that is called implicitly by Python to execute a certain operation on a type, such as addition.  Such methods have names starting and ending with double underscores.  Special methods are documented in [Special method names](https://docs.python.org/3.14/reference/datamodel.html#specialnames).
