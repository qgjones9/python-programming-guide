# [context manager](https://docs.python.org/3.14/glossary.html#term-context-manager)

An object which implements the [context management protocol](../context-management-protocol/index.md) and
controls the environment seen in a [with](https://docs.python.org/3.14/reference/compound_stmts.html#with) statement.  See
[PEP 343](https://peps.python.org/pep-0343/).
