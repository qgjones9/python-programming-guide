# [method resolution order](https://docs.python.org/3.14/glossary.html#term-method-resolution-order)

Method Resolution Order is the order in which base classes are searched for a member during lookup. See [The Python 2.3 Method Resolution Order](https://docs.python.org/3.14/howto/mro.html#python-2-3-mro) for details of the algorithm used by the Python interpreter since the 2.3 release.
