# [awaitable](https://docs.python.org/3.14/glossary.html#term-awaitable)

An object that can be used in an [await](https://docs.python.org/3.14/reference/expressions.html#await) expression.  Can be a [coroutine](../coroutine/index.md) or an object with an [__await__()](https://docs.python.org/3.14/reference/datamodel.html#object.__await__) method. See also [PEP 492](https://peps.python.org/pep-0492/).
