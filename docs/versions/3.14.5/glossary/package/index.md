# [package](https://docs.python.org/3.14/glossary.html#term-package)

A Python [module](../module/index.md) which can contain submodules or recursively,
subpackages.  Technically, a package is a Python module with a
`__path__` attribute.

See also [regular package](../regular-package/index.md) and [namespace package](../namespace-package/index.md).
