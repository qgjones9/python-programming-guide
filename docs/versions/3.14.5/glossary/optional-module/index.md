# [optional module](https://docs.python.org/3.14/glossary.html#term-optional-module)

An [extension module](../extension-module/index.md) that is part of the [standard library](../standard-library/index.md),
but may be absent in some builds of [CPython](../CPython/index.md),
usually due to missing third-party libraries or because the module
is not available for a given platform.

See [Requirements for optional modules](https://docs.python.org/3.14/using/configure.html#optional-module-requirements) for a list of optional modules
that require third-party libraries.
