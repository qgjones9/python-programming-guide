# [token](https://docs.python.org/3.14/glossary.html#term-token)

A small unit of source code, generated by the [lexical analyzer](https://docs.python.org/3.14/reference/lexical_analysis.html#lexical) (also called the *tokenizer*). Names, numbers, strings, operators, newlines and similar are represented by tokens.

The [tokenize](https://docs.python.org/3.14/library/tokenize.html#module-tokenize) module exposes Python’s lexical analyzer. The [token](https://docs.python.org/3.14/library/token.html#module-token) module contains information on the various types of tokens.
