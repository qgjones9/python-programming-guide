# [context management protocol](https://docs.python.org/3.14/glossary.html#term-context-management-protocol)

The [__enter__()](https://docs.python.org/3.14/reference/datamodel.html#object.__enter__) and [__exit__()](https://docs.python.org/3.14/reference/datamodel.html#object.__exit__) methods called by the [with](https://docs.python.org/3.14/reference/compound_stmts.html#with) statement.  See [PEP 343](https://peps.python.org/pep-0343/).
