# [module spec](https://docs.python.org/3.14/glossary.html#term-module-spec)

A namespace containing the import-related information used to load a module. An instance of [importlib.machinery.ModuleSpec](https://docs.python.org/3.14/library/importlib.html#importlib.machinery.ModuleSpec).

See also [Module specs](https://docs.python.org/3.14/reference/import.html#module-specs).
