# [f-strings](https://docs.python.org/3.14/glossary.html#term-f-strings)

String literals prefixed with `f` or `F` are commonly called
“f-strings” which is short for
[formatted string literals](https://docs.python.org/3.14/reference/lexical_analysis.html#f-strings).  See also [PEP 498](https://peps.python.org/pep-0498/).
