# [statement](https://docs.python.org/3.14/glossary.html#term-statement)

A statement is part of a suite (a “block” of code).  A statement is either an [expression](../expression/index.md) or one of several constructs with a keyword, such as [if](https://docs.python.org/3.14/reference/compound_stmts.html#if), [while](https://docs.python.org/3.14/reference/compound_stmts.html#while) or [for](https://docs.python.org/3.14/reference/compound_stmts.html#for).
