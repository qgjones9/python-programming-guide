# [Base classes](https://docs.python.org/3/library/exceptions.html#base-classes)

The following exceptions are used mostly as base classes for other exceptions.

## Table of contents

Mirrors the official Python 3 library index for this section. Each link opens a stub page whose H1 links to the canonical docs.

| Exception | Description |
|-----------|-------------|
| [BaseException](baseexception/index.md) | Root of all built-in exceptions; not meant for direct inheritance in user code (use Exception instead). |
| [Exception](exception/index.md) | Base for all built-in, non-system-exiting exceptions; recommended base for user-defined exceptions. |
| [ArithmeticError](arithmeticerror/index.md) | Base class for arithmetic errors such as OverflowError, ZeroDivisionError, and FloatingPointError. |
| [BufferError](buffererror/index.md) | Raised when a buffer-related operation cannot be performed. |
| [LookupError](lookuperror/index.md) | Base class for invalid key or index errors (IndexError, KeyError); may be raised by codecs.lookup(). |
