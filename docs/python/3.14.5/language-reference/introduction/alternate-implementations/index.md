# [Alternate Implementations](https://docs.python.org/3/reference/introduction.html#alternate-implementations)

Though there is one Python implementation which is by far the most popular, there are some alternate implementations which are of particular interest to different audiences.

| Implementation | Description |
|----------------|-------------|
| [CPython](https://docs.python.org/3/) | The original and primary Python implementation, written in C. New features appear here first. |
| [Jython](https://www.jython.org/) | Python for Java platforms; runs on the JVM and integrates with Java libraries. |
| [Python for .NET](https://pythonnet.github.io/) | Uses CPython but enables direct access to .NET libraries from Python. |
| [IronPython](https://ironpython.net/) | Python implementation for .NET that compiles code to .NET assemblies. |
| [PyPy](https://pypy.org/) | A fast Python implementation written in Python, featuring a JIT compiler and advanced features. |
