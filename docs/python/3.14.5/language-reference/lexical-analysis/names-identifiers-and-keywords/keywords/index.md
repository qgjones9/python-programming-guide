# [Keywords](https://docs.python.org/3/reference/lexical_analysis.html#keywords)

The following names are Python **keywords**—reserved words that have special meaning in the language and cannot be used as ordinary identifiers (such as variable or function names). Each keyword serves a specific syntactic or semantic role:

| Keyword   | Description                                                              |
|-----------|--------------------------------------------------------------------------|
| False     | Boolean false value.                                                     |
| None      | Represents the absence of a value.                                       |
| True      | Boolean true value.                                                      |
| and       | Logical AND operator.                                                    |
| as        | Alias for import; also context manager in `with`.                        |
| assert    | For debugging: raises error if condition is false.                       |
| async     | Marks an async coroutine or context.                                     |
| await     | Waits for completion of an awaitable in async code.                      |
| break     | Exits the nearest enclosing loop.                                        |
| class     | Declares a new class.                                                    |
| continue  | Skips the rest of the loop body and continues with next iteration.       |
| def       | Declares a function or method.                                           |
| del       | Deletes a variable, attribute, or item.                                  |
| elif      | Else-if branch in conditional statements.                                |
| else      | Final branch in an if/elif/else construct or loops.                      |
| except    | Exception handler in a try statement.                                    |
| finally   | Ensures a block runs no matter how the try statement exits.              |
| for       | Begins a loop iterating over a sequence.                                 |
| from      | Used with import to specify source module for imports.                   |
| global    | Declares that a variable refers to module-level scope.                   |
| if        | Begins a conditional statement.                                          |
| import    | Imports modules or objects.                                              |
| in        | Checks membership in a collection or sequence.                           |
| is        | Tests object identity.                                                   |
| lambda    | Creates an anonymous (inline) function.                                  |
| nonlocal  | Declares that a variable refers to the nearest enclosing non-global scope.|
| not       | Logical NOT operator.                                                    |
| or        | Logical OR operator.                                                     |
| pass      | A no-operation statement (does nothing).                                 |
| raise     | Raises an exception.                                                     |
| return    | Exits a function and returns a value.                                    |
| try       | Begins a block to handle exceptions.                                     |
| while     | Begins a loop that repeats as long as a condition is true.               |
| with      | Context manager for resource handling (e.g., file, lock).                |
| yield     | Pauses a generator and yields a value to the caller.                     |

> These keywords are always reserved. They must be spelled exactly as shown and may not be used as variable, function, class, or other identifier names.
