# [free-threaded build](https://docs.python.org/3.14/glossary.html#term-free-threaded-build)

A build of [CPython](../CPython/index.md) that supports [free threading](../free-threading/index.md),
configured using the [--disable-gil](https://docs.python.org/3.14/using/configure.html#cmdoption-disable-gil) option before compilation.

See [Python support for free threading](https://docs.python.org/3.14/howto/free-threading-python.html#freethreading-python-howto).
