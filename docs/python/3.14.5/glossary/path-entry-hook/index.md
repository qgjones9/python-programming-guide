# [path entry hook](https://docs.python.org/3.14/glossary.html#term-path-entry-hook)

A callable on the [sys.path_hooks](https://docs.python.org/3.14/library/sys.html#sys.path_hooks) list which returns a [path
entry finder](../path-entry-finder/index.md) if it knows how to find modules on a specific [path
entry](../path-entry/index.md).
