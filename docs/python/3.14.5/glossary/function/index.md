# [function](https://docs.python.org/3.14/glossary.html#term-function)

A series of statements which returns some value to a caller. It can also
be passed zero or more [arguments](../argument/index.md) which may be used in
the execution of the body. See also [parameter](../parameter/index.md), [method](../method/index.md),
and the [Function definitions](https://docs.python.org/3.14/reference/compound_stmts.html#function) section.
