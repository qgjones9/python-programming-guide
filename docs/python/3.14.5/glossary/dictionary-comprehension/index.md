# [dictionary comprehension](https://docs.python.org/3.14/glossary.html#term-dictionary-comprehension)

A compact way to process all or part of the elements in an iterable and
return a dictionary with the results. `results = {n: n ** 2 for n in
range(10)}` generates a dictionary containing key `n` mapped to
value `n ** 2`. See [Displays for lists, sets and dictionaries](https://docs.python.org/3.14/reference/expressions.html#comprehensions).
