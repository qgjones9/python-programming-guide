# [binary file](https://docs.python.org/3.14/glossary.html#term-binary-file)

A [file object](../file-object/index.md) able to read and write
[bytes-like objects](../bytes-like-object/index.md).
Examples of binary files are files opened in binary mode (`'rb'`,
`'wb'` or `'rb+'`), [sys.stdin.buffer](https://docs.python.org/3.14/library/sys.html#sys.stdin),
[sys.stdout.buffer](https://docs.python.org/3.14/library/sys.html#sys.stdout), and instances of
[io.BytesIO](https://docs.python.org/3.14/library/io.html#io.BytesIO) and [gzip.GzipFile](https://docs.python.org/3.14/library/gzip.html#gzip.GzipFile).

See also [text file](../text-file/index.md) for a file object able to read and write
[str](https://docs.python.org/3.14/library/stdtypes.html#str) objects.
