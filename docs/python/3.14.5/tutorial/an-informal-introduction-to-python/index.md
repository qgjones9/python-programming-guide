A few things to note before we get started:

## Printing to the screen

To get information printed out to the screen use the print function. See example below:
```python
print("Hello, World!") # This will print "Hello, World!" to the screen
```

The print function can take multiple arguments separated by commas. See example below:
```python
print("Hello, World!", "Hello, World!", "Hello, World!") # This will print "Hello, World!, Hello, World!, Hello, World!" to the screen
```

## Comments


Comments start with `#` and are ignored by Python. The python interpreter ignored comments when executing code. Multi-line comments start with `"""` and end with `"""`. See example below:

```python
# This is a comment
print("Hello, World!") # This will print "Hello, World!" to the screen
```

```python
"""
This is a multi-line comment
It can span multiple lines
"""
```
