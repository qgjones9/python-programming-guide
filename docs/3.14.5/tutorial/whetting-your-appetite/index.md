# [Whetting Your Appetite](https://docs.python.org/3/tutorial/appetite.html)

- Python is a powerful, easy-to-learn language with efficient high-level data structures and straightforward object-oriented programming.
- Its simple syntax and dynamic typing make it ideal for scripting and rapid application development on most platforms.
- The Python interpreter and its extensive standard library are freely available across major platforms from https://www.python.org/.
- Python supports extension in C, C++, and other languages, making it suitable both for standalone programs and as an extension language for applications.
- This tutorial gives an informal introduction to Python’s core concepts and features. Prior programming experience is helpful but not strictly required.
- The tutorial is not exhaustive, but aims to showcase Python's main features and style, preparing you to write Python modules and programs and explore the standard library further.
