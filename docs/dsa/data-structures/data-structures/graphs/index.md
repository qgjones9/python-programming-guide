# Graphs

A set of **vertices** (nodes) and **edges** (links); models networks, dependencies, and relationships.

| | |
| --- | --- |
| **What it is** | Edges may be directed or undirected, weighted or unweighted. |
| **Representations** | Adjacency list (sparse), adjacency matrix (dense), or edge list. |
| **When to use** | Social graphs, road maps, compilation units, and state machines. |
| **Classics** | BFS, DFS, shortest path, minimum spanning tree, topological sort. |
