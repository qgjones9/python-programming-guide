# Stacks

A last-in, first-out **LIFO** collection—only the top is immediately accessible.

| | |
| --- | --- |
| **What it is** | Push adds to the “top,” pop removes from the top; often implemented as array or linked list. |
| **Core operations** | `push`, `pop`, and usually `peek` (view top without removing). |
| **When to use** | Function calls, undo stacks, depth-first search, parsing expressions, and backtracking. |
| **Model** | Think of a stack of plates: only the top plate is added or taken first. |
