# Sets

An abstract collection of **unique** elements—membership, insert, and remove are the main focus.

| | |
| --- | --- |
| **What it is** | No duplicate keys; *unordered* sets often use hash tables; *ordered* sets use balanced BSTs. |
| **Core operations** | `insert`, `remove`, `contains`, and iteration in sorted order (if ordered). |
| **When to use** | Deduplication, membership testing, and set algebra (intersection, union) in math libraries. |
| **Related** | *Multiset* (bag) allows duplicate counts. |
