# Algorithms

This hub lists every algorithm page in this section. Each page opens with a short table: what the algorithm does, the core idea, and typical complexity (where it matters most).

Rows below are ordered for coding interview prep—highest typical ask frequency first.

| Topic | What it is | Interview priority | Page |
| --- | --- | --- | --- |
| Dynamic programming | Overlapping subproblems solved once via memoization or tabulation. | High | [Dynamic programming](dynamic-programming/index.md) |
| Backtracking | Choose, explore, undo — systematic search over combinations and constrained paths. | High | [Backtracking](backtracking/index.md) |
| Greedy | Repeatedly take the locally best feasible choice; fast when a greedy-choice proof holds. | High | [Greedy](greedy/index.md) |
| Quicksort | Partitions around a pivot, recurses; fast average case, in place. | High | [Quicksort](quicksort/index.md) |
| Merge sort | Split in half, sort halves, merge—stable, predictable O(n log n) time. | High | [Merge sort](merge-sort/index.md) |
| Quickselect | Finds the k-th element using quicksort-style partitioning. | High | [Quickselect](quickselect/index.md) |
| Heap sort | Build a heap, extract max repeatedly—in-place O(n log n) worst case. | Medium | [Heap sort](heap-sort/index.md) |
| Insertion sort | Inserts each element into its place in a growing sorted region. | Medium | [Insertion sort](insertion-sort/index.md) |
| Radix sort | Sorts by processing digits/characters place by place; not comparison-only. | Medium | [Radix sort](radix-sort/index.md) |
| Bucket sort | Spreads values into buckets, sorts each bucket, then concatenates. | Low | [Bucket sort](bucket-sort/index.md) |
| Selection sort | Grows a sorted front by picking the next smallest (or largest) from the rest. | Low | [Selection sort](selection-sort/index.md) |
| Bubble sort | Swaps adjacent out-of-order pairs until no swaps—simple, usually slow. | Low | [Bubble sort](bubble-sort/index.md) |
| Shell sort | Generalization of insertion sort using a gap sequence, then gap 1. | Low | [Shell sort](shell-sort/index.md) |
